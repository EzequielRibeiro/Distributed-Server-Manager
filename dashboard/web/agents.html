Instalação, localização, atualização e administração dos Agents gerenciados pelo Controller.

Adicionar Agent

Instale manualmente ou permita que o Controller faça o bootstrap Linux via SSH e Windows via WinRM HTTPS.

Sistema
Método

Bootstrap SSH pelo Controller

O Dashboard não aceita senha SSH. O Controller usa sua chave/ssh-agent já configurada, preserva a verificação de host key e exige sudo não interativo no host remoto.

Bootstrap WinRM pelo Controller

A senha não é enviada à Dashboard. Prepare este host uma vez com sudo cap agent winrm-prepare Administrator@HOST; depois a autenticação usa certificado via HTTPS.

Pré-configuração do Agent

A faixa só é criada depois do enrollment, quando o Agent já possui identidade. Isso evita reservas associadas a Agents inexistentes.
