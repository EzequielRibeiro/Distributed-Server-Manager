Autenticação SSH

Escolha senha ou chave SSH. A senha nunca é enviada como valor de formulário: somente o caminho de um arquivo 0600 autorizado. A chave privada permanece no Controller e deve estar em /etc/capivara/ssh/remote-deploy (ou no diretório configurado pelo administrador).
