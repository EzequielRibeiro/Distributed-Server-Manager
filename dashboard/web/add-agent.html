Instalação de Agents em lote

Selecione um CSV. Cada linha será validada e enviada sequencialmente pelo mesmo endpoint usado pelos assistentes individuais.

Colunas obrigatórias: host, ssh_user, region_id e datacenter_id. O padrão é Linux/OpenSSH. Senhas em texto puro não são aceitas.

Pacote local Linux: use a coluna package_file com um arquivo .tar.gz já armazenado no Controller em /var/lib/capivara/agent-packages (ou no diretório configurado por DSM_AGENT_LOCAL_PACKAGE_DIR). Não preencha release_tag na mesma linha. O Controller valida o pacote e o transfere por SCP para o host. Pacote local Windows ainda não está habilitado.

Proteção contra duplicidade: hosts repetidos no mesmo CSV são recusados. Se o mesmo arquivo já tiver sido executado neste navegador, uma nova execução exige confirmação explícita. O Controller também recusa reinstalação automática quando detecta um Agent já presente no host.
