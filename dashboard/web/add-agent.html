Instalação do Agent

Instale manualmente por instrução ou permita que o Controller faça o bootstrap Linux via SSH e Windows via WinRM HTTPS.

Sistema
Método

Bootstrap SSH pelo Controller

O Dashboard não aceita senha SSH. O Controller usa sua chave/ssh-agent já configurada, preserva a verificação de host key e exige sudo não interativo no host remoto.

Bootstrap WinRM pelo Controller

Prepare uma vez com sudo cap agent winrm-prepare Administrator@HOST. A Dashboard usa certificado e nunca recebe a senha.

Pré-configuração do Agent

A faixa só é criada depois do enrollment, quando o Agent já possui identidade.
