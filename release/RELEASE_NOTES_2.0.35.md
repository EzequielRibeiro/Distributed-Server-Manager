# Capivara DSM 2.0.35

Patch release after Capivara DSM 2.0.34 to publish the runtime/catalog completion work and the managed game firewall implementation validated on the current main branch.

## Managed game firewall

- Add canonical runtime network exposure with explicit `public`, `private` and `none` classifications.
- Keep exposure fail-closed: reserving a port does not implicitly make it publicly reachable.
- Propagate the canonical exposure policy from Controller to Linux, Hybrid and Windows Agents without allowing UI overrides.
- Integrate managed firewall reconciliation into instance provision, reconcile and remove lifecycle operations.

## Linux and Hybrid

- Add the privileged Linux UFW reconciler with per-instance ownership metadata.
- Remove only stale rules owned by the same instance.
- Add dedicated Hybrid firewall systemd integration.
- Restrict Hybrid polkit authorization to valid firewall unit names and the `start` verb.
- Ensure existing standalone Linux Agents create the managed firewall state directory during update.
- Preserve safe cleanup semantics during instance removal.

## Windows Agent

- Add managed Windows Firewall/NetSecurity reconciliation under the existing SYSTEM supervisor.
- Preserve legacy unmanaged runtime behavior without implicitly opening ports.
- Integrate firewall creation and cleanup into Windows instance lifecycle.
- Validate the implementation on native `windows-latest` CI.

## Port ownership and safety

- Enforce and test uniqueness of `(node_id, protocol, port)` reservations.
- Preserve allocator rejection of already reserved or occupied protocol/port pairs.
- Keep firewall rule ownership compatible with the global host firewall model.
- Prevent one instance from removing a firewall permission legitimately owned by another instance.

## Catalog and runtime completion

- Publish the remaining runtime profiles and normalize network contracts across the supported catalog.
- Include completed FiveM, Luanti, Valheim, ARK: Survival Ascended and additional runtime/profile parity work.
- Preserve runtime-specific private administrative ports such as RCON/API endpoints unless explicitly marked public.

## Regression protection

- Cover network exposure policy and fail-closed behavior.
- Cover Linux privileged firewall reconciliation, idempotency and removal.
- Cover Hybrid privilege-boundary and updater compatibility.
- Cover Windows managed firewall lifecycle and native package parity.
- Cover managed firewall port uniqueness and allocator invariants.
