# Capivara DSM 2.0.32

Release focused on Hybrid Customer Workspace convergence, backup/restore reliability, authoritative instance runtime telemetry and rich provisioning-failure diagnostics after Capivara DSM 2.0.31.

## Hybrid Customer Workspace and backup/restore

- Restore Customer Workspace parity for instances hosted by the embedded Hybrid Agent using the canonical Linux Agent executors.
- Keep private per-instance storage boundaries while enabling privileged, systemd-scoped Hybrid backup restore.
- Allow retries against the same backup artifact without losing the immutable backup identity or historical job ledger.
- Permit runtime traversal only where required for shared Hybrid game-data while retaining private control-plane and backup directories.
- Synchronize Customer runtime controls with observed state and expose scoped live instance logs without granting the Dashboard direct journal privileges.

## Instance runtime and telemetry

- Make current Agent runtime health authoritative for Agent-owned instances instead of presenting stale Controller state as live truth.
- Preserve `unknown` separately from confirmed `offline` and keep list/detail runtime projections consistent.
- Add per-instance systemd network accounting, native DayZ A2S telemetry and all-or-unknown storage measurement semantics.
- Preserve storage quota separately from measured usage and avoid rendering unavailable telemetry as false zeroes.

## Provisioning failures and administrative diagnostics

- Keep failed provisioning below 100%; only successfully completed provisioning reaches 100%.
- Capture bounded failure context including stage, Agent/node, instance, correlation id, exception type, safe error summary, source and failure timestamp.
- Sanitize Agent-controlled diagnostic data before Controller persistence and redact credentials, bearer tokens, Steam login data and sensitive host paths.
- Keep traceback out of the common provisioning status projection and expose sanitized traceback only through the explicit Admin-only diagnostic path.
- Create deduplicated CRITICAL instance alerts and correlatable UEP failure events with safe operational context.
- Fix Controller instance management navigation so `Gerenciar` opens the existing instance workspace rather than the game catalog.

## CI and release reliability

- Give governance gates unambiguous names for branch/ruleset enforcement.
- Isolate validation setup and the External Controller Agent E2E from unrelated Google Chrome APT repository index failures without weakening their tests.
