# Capivara DSM 2.0.29

Maintenance release focused on safer in-place updates after the 2.0.28 catalog milestone.

## Update safety

- Preserve existing instance and game data in place during updates instead of copying mutable instance trees into the release staging area.
- Keep pre-backup and pre-activation guards ahead of destructive update steps.
- Avoid rollback when an update is refused during preflight, preventing an unnecessary restore path from running before activation begins.
- Add regression coverage for the guarded update sequence and data-preservation behavior.

## Release scope

- Includes main through PR #370 (`fix(update): preserve instance data without copying and guard rollback`).
- Retains the complete 2.0.28 catalog baseline, including Luanti 5.17.0, FiveM, Valheim and ARK: Survival Ascended, with zero deferred runtimes.
- Release artifacts, checksums and manifests are generated by the repository Release workflow for DSM and standalone Linux/Windows Agents.
