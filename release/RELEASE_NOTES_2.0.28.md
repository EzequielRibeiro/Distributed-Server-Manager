# Capivara DSM 2.0.28

Release consolidating the published game catalog and instance isolation improvements merged since 2.0.27.

## Catalog

- Add GameDefinition metadata for all 20 published games and hierarchical Game → Edition → Distribution/variant → RuntimeDefinition discovery through the authenticated Dashboard API and CLI.
- Preserve existing runtime IDs, flat discovery APIs and executable RuntimeDefinition contracts.
- Publish Luanti 5.17.0 using the official source archive and typed CMake server build, and activate FiveM, Valheim and ARK: Survival Ascended through supported Agent strategies.
- Complete the catalog runtime readiness work for Minecraft Java/Bedrock, Mindustry, Source games, Arma 3, Rust and Palworld; the deferred runtime backlog is empty.
- Enforce game-reference validation and resource-profile parity in catalog CI.

## Reliability

- Isolate mutable runtime state for Source games, DayZ missions, Windows DayZ and The Isle; add runtime-home isolation coverage.
- Improve Hybrid Agent provisioning job processing, Steam provider settings and observability telemetry persistence.
- Preserve failed customer instances and retry access; correct workspace asset scope and display server contract references.

## Release scope and validation

- Includes the main branch through PR #368 and the release metadata commit.
- PR #345 (alternative reversible Hybrid Agent lifecycle implementation) remains open and is not included. Main already contains the Hybrid demotion fix from PR #349.
- Catalog validation passed 40 Python tests and 50 subtests, plus the existing catalog CLI regression suite. All 32 checks on PR #368 and all 31 observed checks on its main merge passed.
- Installer archives, checksums and manifests are generated by the repository Release workflow for DSM and standalone Linux/Windows Agents.
